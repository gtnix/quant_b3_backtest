Onde o código gera esses arquivos
O backtester CLI gera os 4 arquivos para todo backtest executado:
crates/backtester_cli/src/output.rs         → Gera os arquivoscrates/combiner_runner/src/executor.rs      → Chama o backtester
O timeseries.csv é usado posteriormente para:
Crosscheck (crosscheck.rs) - recalcula métricas a partir do NAV
Asset Attribution (run_campaign.rs) - analisa composição do portfolio
Ambos os usos só precisam dos backtests validados (51), não dos 96,995.
Projeção para campanhas maiores
Duração	Backtests (estimado)	Espaço Consumido
5 min	96,995	6.7 GB
30 min	~580,000	~40 GB
1 hora	~1,160,000	~80 GB
4 horas	~4,640,000	~320 GB
Resumo da causa raiz
94% do espaço vem de um único arquivo (timeseries.csv) que é gerado para todos os 96,995 backtests, quando apenas 51 são efetivamente utilizados
O formato CSV texto usa 2-3x mais espaço que formatos binários equivalentes
Cada backtest tem sua própria pasta, gerando 379 MB de overhead de filesystem
Colunas vazias são incluídas em todos os arquivos (4 das 8 colunas são sempre vazias neste run)
